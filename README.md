# Container Sorter（荒野/漫漫长夜 v2.55）

打开容器后按一下 **R**（可改），背包里凡是「该容器中已经存在的同种物品」全部搬进容器，直到碰上容器的重量上限为止。

与游戏自带的「全部转移」区别：**只搬"容器里已经有"的那些种类**，不会把背包塞空，也不会把容器原有的分类习惯打乱。

## 行为细节

- 只在 **容器面板打开** 时响应，其它时候按键无副作用。
- 匹配依据是 **prefab 名**（比较时去掉 Unity 的 `(Clone)` 后缀），所以 RUINED 状态也照样算同种物品。
- 每件都按容器 **剩余容量** 判断：放得下就搬，放不下就跳过并继续尝试下一件（小件还能挤进去），装满了提前结束。
- 堆叠物品（火柴、箭、子弹等）整堆搬，不拆堆 —— 和原版「转移」一致。
- 默认跳过：穿戴中的衣物、手上拿着的物品、随身小包（satchel）里的物品、隐藏物品（水分/燃料这类内部 supply）。
- 迁移完会刷新容器面板，重量条/物品格当场更新。

## 设置（选项 → Mod Settings → Container Sorter）

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 整理键 | R / T / F / G / H / J / K / L / N / M / B / V / C / X / Z | R |
| 需要同时按住 Ctrl | 防和其它 mod 抢键 | 关 |
| 跳过穿戴中/手持物品 | 关掉等于强制脱衣服 | 开 |
| 跳过小背包里的物品 | | 开 |
| 输出详细日志 | 逐件打印迁移明细 | 关 |

## 日志排查

`MelonLoader/Latest.log` 里搜索 `[容器]`：

```
[Container] 容量 30kg，已用 4.2kg，剩余 25.8kg
整理完成：放入 3 件（2.4kg），1 件放不下，容器剩余 23.4kg
```

若出现 `容器没有接收 xxx，已退回背包`，说明原版容量判定比本 mod 更严（或容器拒绝该分类），
物品会退回背包、不会丢。
