# Container Sorter（荒野/漫漫长夜 v2.55）

打开容器后按一下 **R**（可改，按键可自由重绑定），背包里凡是「该容器中已经存在的同种物品」全部搬进容器，直到碰上容器的重量上限为止；可堆叠物品会直接并进容器里已有的那一堆。「保留一个」清单里的物品只搬走多余的部分。

与游戏自带的「全部转移」区别：**只搬"容器里已经有"的那些种类**，不会把背包塞空，也不会把容器原有的分类习惯打乱。

## 行为细节

- 只在 **容器面板打开** 时响应，其它时候按键无副作用。
- 匹配依据是 **prefab 名**（比较时去掉 Unity 的 `(Clone)` 后缀），所以 RUINED 状态也照样算同种物品。
- 每件都按容器 **剩余容量** 判断：放得下就搬，放不下就跳过并继续尝试下一件（小件还能挤进去），装满了提前结束。
- **堆叠合并**（v1.1 新增）：容器里已有同款、且状态（condition）差值在原版允许范围内的堆叠时，直接把数量并进那一堆
  —— 20 根雪松木柴 + 容器里 1 根 = 一根 21 的堆，而不是两堆。
  - 液体（按体积记账）不合并；状态差超限（比如 90% 新鲜的肉 vs 快烂的肉）也不合并，按原版习惯落成新的一堆。
  - 合并前会核对「数量涨了重量是否也涨」；万一某类物品的账本不跟 `m_Units` 走，会回滚并退回普通迁移，不会算错容量。
- **忽略清单**（v1.2 新增，v1.3 加了分区）：`Mods/ContainerSorterIgnore.txt` 控制哪些物品不搬。
  - `#全部无视/Ignore All` 之后的物品 **一个都不搬**；`#保留一个/Keep One` 之后的物品 **背包留 1 个，其余搬走**。
  - 第一次启动时自动创建该文件（内容是说明+示例，全部注释掉，默认不忽略任何东西）。
  - 每行一个 prefab 名，`#` / `//` 开头是注释，行尾也可跟注释；大小写不敏感，`GEAR_` 前缀可省略（`Acorn` 等价 `GEAR_Acorn`）。
  - 「保留一个」对非堆叠物品（工具类，如 Hacksaw / SewingKit）同样有效：背包里同种有好几把时留一把，其余搬进容器。
  - **耐久优先**（v1.4）：同种物品耐久不同时，背包留耐久最低的那件，**状态好的优先收进容器**（v1.3 是反过来的）。
    设置里关掉「保留时优先把高耐久放进容器」可恢复旧行为。
  - 改完存盘即生效：每次按整理键都会比对文件修改时间，变了就重读，**不需要重启游戏**。
- 堆叠物品整堆搬，不拆堆（和原版「转移」一致）；只有「保留一个」需要拆分时才按数量拆。
- 默认跳过：穿戴中的衣物、手上拿着的物品、随身小包（satchel）里的物品、隐藏物品（水分/燃料这类内部 supply）。
- 迁移完会刷新界面（v1.5 加强）：先 `Panel_Container.RefreshTables()` 立刻重建背包表+容器表，
  再 `Panel_Container.ForceRefresh()` 让下一帧重算过滤列表与选中项（直接改数据绕过了原版 `OnMoveItem`，
  过滤列表会残留已搬走的条目，只做前一步时偶发「界面上还摆着已经搬走的东西」），
  最后如果背包面板在显示中就再调一次 `Panel_Inventory.RefreshTable()`。三步各自独立 try，互不影响。

## 设置（选项 → Mod Settings → Container Sorter）

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 整理键 | 点一下设置项，再按下想绑的键（键盘/鼠标键都行） | R |
| 需要同时按住 Ctrl | 防和其它 mod 抢键 | 关 |
| 合并可堆叠物品 | 关掉则每件单独落一堆 | 开 |
| 跳过穿戴中/手持物品 | 关掉等于强制脱衣服 | 开 |
| 跳过小背包里的物品 | | 开 |
| 启用忽略清单 | 关掉则 `ContainerSorterIgnore.txt` 不生效（两种分区都不生效） | 开 |
| 保留时优先把高耐久放进容器 | 「保留一个」时背包留耐久最低的，好的收进容器 | 开 |
| 输出详细日志 | 逐件打印迁移明细 | 关 |

> 按键绑定走 ModSettings 自带的 rebinding 控件（`GUIBuilder.AddKeySetting`），字段类型是 `KeyCode`。
> 从 v1.0 升上来的旧 `Mods/ContainerSorter.json` 里 `Key=0` 会被识别为「未绑定」，启动时自动改成 R 并写回。
